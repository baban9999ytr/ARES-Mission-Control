# MISSION_SCREENSHOTS

30 görev için JSON briefing dosyaları oluşturuldu.

Şu an gerçek CTX rasterı ARES'e yüklenip çalıştırılmadığı için sahte ekran görüntüsü üretilmedi. Gerçek doğrulamada her görev için mümkünse PNG ekran görüntüsü eklenmeli ve JSON içindeki gerçek Shortest/Terrain Preferred metrikleri doldurulmalıdır.

Bu klasörün amacı sentetik demo ile gerçek Mars verisini birbirine karıştırmamaktır.
